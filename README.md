# 📖 Overview

An AI-powered web application developed during my internship that classifies uploaded fruit and vegetable images as **Fresh** or **Rotten** using a trained TensorFlow deep learning model.

Users upload an image through a Flask web interface and instantly receive the predicted class along with a confidence score.

---

# ✨ Features

- 🍎 Fresh vs Rotten Classification
- 🧠 TensorFlow CNN Model
- 📷 Image Upload
- 📊 Confidence Score
- 🌐 Flask Web Interface
- ⚡ Real-time Prediction
- 📱 Responsive UI
